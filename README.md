# Escuela de Danza Pavlova — website prototype

Open `index.html` in a browser to preview the website.

## Before publishing

- Add academy photographs.
- Confirm programs, ages, schedule, prices, full street address, and email.
- Create and connect a Google registration/free-trial form.
- Choose a payment provider and connect the payment button.
- Publish the folder through GitHub Pages.

The site is a responsive, self-contained HTML prototype with Spanish and English content.
